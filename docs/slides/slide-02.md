## O DESAFIO

- LLMs revolucionam aprendizado de línguas, mas...
- 📉 **Lacuna crítica:** 87% dos estudos não são replicáveis [Yan et al., 2024]
- ⚠️ **Riscos em produção:** Prompt injection, alucinações, vendor lock-in [Benjamin et al., 2024; Armbrust et al., 2010]
- 🔧 **Vácuo metodológico:** Falta de especificações validadas para produção [Sculley et al., 2015; Amershi et al., 2019]
