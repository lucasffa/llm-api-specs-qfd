## Método QFD Adaptado

---

## PROCESSO

```
1️⃣ ELICITAÇÃO           2️⃣ VALIDAÇÃO QFD         3️⃣ ESPECIFICAÇÃO
Revisão literatura  →   Scoring 5 critérios   →   Gherkin + OpenAPI
(22 requisitos)         (IAR ≥ 2.5 = Fundamental) (Contratos testáveis)
```

## ÍNDICE DE ADEQUAÇÃO DO REQUISITO (IAR)

```
IAR = Σ(Critério_i × Peso_i) / Σ(Peso_i)
```

## CRITÉRIOS DE VALIDAÇÃO

| Critério | Peso | Escala |
|----------|------|--------|
| Viabilidade Técnica | 3 | 1-3 |
| Testabilidade | 3 | 1-3 |
| Coesão de Domínio | 2 | 1-3 |
| Impacto na Solução | 2 | 1-3 |
| Complexidade (invertida) | 1 | 1-3 |
